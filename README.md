# Регистрация мероприятий — Backend

Серверная часть системы регистрации участников мероприятий с QR-кодами.
Отвечает за учёт мероприятий и участников, генерацию QR-кодов, отметку
присутствия на входе и отдаёт данные фронтенду через REST API.

## Стек

- **Go** — основной сервер
- **PostgreSQL** — хранение мероприятий, участников и отметок
- REST API для фронтенда

## Возможности

- Учёт мероприятий и регистрация участников
- Генерация уникального QR-кода для каждого участника
- Отметка присутствия (check-in) по сканированию QR-кода
- Выдача списков и статистики по участникам через API

## Структура проекта

```
cmd/         — точка входа (сервер)
internal/    — бизнес-логика
migrations/  — миграции базы данных
```

## Конфигурация

Настройки задаются через переменные окружения (см. `.env.example`):

| Переменная     | Назначение                        |
| -------------- | --------------------------------- |
| `DATABASE_URL` | строка подключения к PostgreSQL   |
| `PORT`         | порт, на котором работает сервер   |

## Запуск

1. Заполните переменные окружения (например, в файле `.env`).

2. Примените миграции из папки `migrations/` к базе PostgreSQL.

3. Запустите сервер:

```bash
go run ./cmd/server
```
